# 2026-10-19 · 濕鏡頭只在 0.9 m 以上的水、光束不變暗；漂浮玩具依階段褪色

- **決策**：
  - 鏡頭只在水深 ≥ 0.9 m 時變濕：踏進去立刻濕一次，在裡面走動每 3–8 秒再濕；更淺的水完全不濕；入水水聲照舊
  - 濕鏡頭的扭曲改為「照常畫到螢幕 → 複製螢幕成貼圖 → 透過水滴貼回」。原本先畫進 sRGB 離屏貼圖，加法混合的光束在線性空間相加而變暗（同一畫面平均亮度 198 → 185）
  - 漂浮玩具：區塊生成時依壓抑度決定種類。壓抑度 < 0.25（第 1 階段）全是鮮豔泳圈、浮板、海灘球（2:1:1）；0.25 → 0.75 褪色半沉舊泳圈比例 0 → 100%；≥ 0.75（第 4 階段）只剩舊泳圈。已生成的區塊（含地標區域）不再改變
