# 效能測試掉到門檻下

### 1. 內顯 A11b 某一段 fps < 58 或慢幀 > 2%

(2026-10-19・Playwright Chromium `--force_low_power_gpu`、CPU 降速 4 倍・Opus 5.5)

`perf-igpu` 某段紅 → 1. 看 8080／8090 有沒有別的伺服器或 Playwright 在跑，有就等它結束再單獨重跑 2. 同機同時段跑改動前的版本（`git archive HEAD js | tar -x -C <scratchpad>/base`，再把 `tools/serve.mjs` 指過去或改用 node 模擬）比對同一段 3. 只有本次版本紅：用 node 模擬載入器（每幀呼叫一次 `ChunkManager.update`，記每次耗時），分出是「生成」還是「網格」那一步超過約 1 ms，再看那一步能不能拆成多幀 → 環境負載，或單幀工作太大

- 2026-10-19 實例：傳送進區域時，區域區塊與相鄰樓梯房在同一幀整塊生成（樓梯房 p99 33 ms）。改成 `World.prepare` 每幀只做一個區域、一個網格階段或一個房間後五段全過
