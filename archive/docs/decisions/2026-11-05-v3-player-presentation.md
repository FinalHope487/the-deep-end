# Decision: v3 interaction, controls, quality and first play (2026-11-05)

Source: user answers Q9, Q20, Q33, Q34, Q39, Q40, Q42-Q44 in `docs/handoff/core-aspect-answers-2026-11-05.md`.

| ID | Decision |
|---|---|
| Q9 | Signs, chalk and small finds stay quiet. Key directions stay clear |
| Q33 | Core interaction is explore and pick up. Add no required switch, door puzzle or device |
| Q34 | No gamepad support |
| Q20 | No notice when auto quality changes. The level shows in settings |
| Q39 | Phone: support portrait and landscape |
| Q40 | Return from another app: show a pause state with a clear Continue button |
| Q42 | Offer larger text and higher contrast |
| Q43 | Show a short hint at the first move, pick up and pause |
| Q44 | A new world starts on dry tile floor with a bright pool or colonnade ahead |

## Limits

- Q33 limits new required interaction only. Keep stairs, usable slides, level jump, pick up, pause and settings, and the exit.

## Cost to reverse

UI, input and flow change. The core world structure does not change.
